An island that keeps an eye on your AI coding agents

Mayak lives at the top of your screen. It shows every Claude Code, Codex and Antigravity session, which of them are waiting for you, and lets you answer a permission request or a question with a click. Luch, a small fire spirit, shows how it is going.

DownloadSource on GitHub

Windows 10/11, and macOS 13+ on Apple silicon. The Windows builds are not code-signed, so SmartScreen warns about an unknown publisher; the Mac build is signed ad hoc and opens through System Settings → Privacy & Security → Open Anyway.
  • Every agent session grouped by project, with what it is doing now, its context fill and its git state.
  • Allow or Deny from the island, answers to the agents' questions, the right window one click away.
  • A chat with your own agent CLIs, with no API key: Claude Code, Codex, Gemini CLI and Cursor Agent.
  • Plan limits, balances, GitHub and GitLab pull requests and CI, a player, a focus timer and your usage stats.
  • No telemetry, no account. Keys stay in your system's credential store.

Mayak is built on Coucou by Louis Raillé and released under the MIT license.
