## Known limits left in place

- Stats: one current UTC offset is applied to all days. After a DST change, rows within an hour of midnight move by a day, and the whole cache is rebuilt once. Moscow time has no DST.
- Stats: an all-zero Codex record counts as a request.
- MSI: it installs for all users and needs administrator rights. Its uninstaller has none of the NSIS hooks: it leaves `%LOCALAPPDATA%\Mayak\{bin,inbox,mayak.log}` behind and does not remind you about the Codex integration. Do not install both the MSI and the setup.exe.

## Утренний чек-лист

Run the branch with `cd windows && npm run tauri dev`, or build it and install over 0.2.0.

1. **File drop (item 1):**
   - [ ] Drop a file from Explorer onto the open island, then onto the collapsed strip. The file card appears.
   - [ ] Start a drag and release it somewhere else. The island does not stay in drop mode.
   - [ ] Drop a folder, and a file over 200 MB. Each gets a clear refusal, and nothing hangs.
   - [ ] Drop a file named `CON.txt` or `report.` (with a trailing dot). It is copied to the inbox as `_CON.txt` or `report`.
2. **Launcher:**
   - [ ] Pick Claude in Cursor. Cover three cases: a project open in its own window, a project inside a workspace, and a project that is not open. The prompt lands in the Claude field and is not sent.
   - [ ] Claude Desktop: a dropped file goes in with the prompt.
3. **Focus mode (item 3):**
   - [ ] Start focus from the header button, then from the tray. The two stay in sync.
   - [ ] During focus, "done" and "error" alerts make no sound and do not open the island. A permission request still comes through (the setting is on by default). The strip is violet.
   - [ ] When focus ends, the summary card appears with the right counts. If a permission card was open at that moment, the summary appears after it closes.
4. **Player (item 4):**
   - [ ] Play Spotify, then YouTube in a browser. The row appears at the bottom of the home page, and ⏮ ⏯ ⏭ work.

   - [ ] Open the Stats tab. Time the first count (it reads every transcript once). Open it again: this time it should be instant, from the cache.
   - [ ] The 7 and 30 day totals look plausible next to the Claude and Codex usage pages.
6. **MSI (item 7):**
