## 2. Детали

### (a) Интеграции без лишних перерисовок (топ-1)

- Где: `windows/src/island/integrations.ts`, функция `handle()` (строки 38-47 запись, 83 `State.notify()`).
- Что сделать: до записи сравнить новую запись с `previous` (`data` — `JSON.stringify` или поверхностное сравнение; `error`; `loaded`). Если всё равно и `update.event` нет — выйти без `notify`. События (новый запуск n8n и т. п.) по-прежнему проходят.
- Rust (`src-tauri/src/integrations.rs`) трогать не обязательно; сравнение на странице проще и покрывает все интеграции разом.
- Проверка: `scripts/checks/` — два одинаковых обновления дают один `notify`, изменённое — второй, обновление с `event` — всегда.
- Цена бага небольшая (лишний кадр раз в 15–30 с при открытом острове), но исправление дешёвое и поддерживает правило «кадр только когда что-то изменилось».

### (b) Ограничение `dt` (топ-2)

- `windows/src/island/island.ts:1709`: `const dt = Math.min(0.05, (nowMs - this.lastFrame) / 1000);`.
- На 15 fps (компактный остров) реальный шаг ~0,066 с, учитывается 0,05 — частицы и ноты (`luch/engine.ts:745`, `p.age += dt`), пружина рта и сглаживание идут на 25 % медленнее. Огонь, танец и твины от `performance.now` (`engine.ts:134`, `render.ts:85`) не страдают, поэтому части Луча идут вразнобой.
- Исправление: ограничение около 0,1 с (защита от долгой паузы вкладки остаётся). Пружины острова уже дробят шаг до 1/240 (`core/anim.ts:78`). Единственный явный Эйлер в движке — пружина рта (`engine.ts:748-753`, ω = 2π/0,25 ≈ 25 рад/с): цикл по подшагам ≤ 0,05 с, как делает upstream.
- Проверка: в `scripts/checks/` — пружина рта за 1 с при `dt` 0,066 и при 0,016 приходит в одну точку с допуском.

### (c) Замеры, блокировка экрана, WebGL→2D (топ-3)

1. **Сборка для замеров.** Повторить замер 12–14 % на `npm run tauri build`. `tauri dev` отдаёт страницу через Vite с HMR, Rust собран в debug; урок upstream (#481) — неоптимизированная сборка удваивала цену отрисовки.
2. **Блокировка.** Замерить CPU с компактным островом при Win+L и при выключенном дисплее. Если цикл огня продолжает идти: в Rust — `WTSRegisterSessionNotification` (`WTS_SESSION_LOCK`/`UNLOCK`) и `RegisterPowerSettingNotification(GUID_CONSOLE_DISPLAY_STATE)`; остановить `PollGate` (`src-tauri/src/island.rs`) и отправить странице событие, останавливающее цикл, либо выставить `IsVisible = false` у контроллера WebView2. Продолжение правила «0 % CPU, когда не видно».
3. **Копирование WebGL→2D (гипотеза, не из upstream).** Огонь рендерится в общий WebGL-canvas с `preserveDrawingBuffer: true` (`luch/fire.ts:44`) и копируется `drawImage` в 2D-canvas Луча (`luch/render.ts:84-91`) каждый кадр и для каждого мини. Если маленький 2D-canvas в WebView2 не ускорен GPU, это чтение с GPU в каждом кадре. Плюс окно в компактном режиме остаётся 720×560 (`core/layout.ts:64-65`). Проверить трассировкой (DevTools Performance или `edge://tracing` в WebView2); если подтвердится — рисовать огонь прямо в видимый WebGL-canvas или сжимать окно в компактном режиме. Это может быть основной частью 12–14 %.

### (d) Пакет мелкой экономии (топ-4) и долгие состояния на 60 fps

- **Мини-Лучи.** `tickMiniBots(dt, …)` в каждом кадре (`island.ts:1749`, `minibots.ts:89-102`), у каждого свой `renderFire` и `drawImage`. Копить `dt` и рисовать не чаще `fireFps`. Большую часть времени мини и так идут на 15–20 fps, вид не изменится.
- **Полоска отсчёта.** `@keyframes countdown-shrink` с `width: 160px → 0` (`style.css:210-217`) → `transform: translateX(-50%) scaleX(1 → 0)`; полоска 2 px со скруглением 2 px, искажение концов проверить скриншотом. Не меняет вид существующей полоски (правило «не перестилизовывать то, что уже есть»).
- **Искры.** Один спрайт свечения на каждый цвет `palette.light` (OffscreenCanvas), рисовать `drawImage` с `globalAlpha` и масштабом `r`. Выигрыш небольшой — подтвердить профилем.
- **Долгие состояния (не из upstream).** `engine.busy` истинно при `cfg.bounces/scans/breathes/zz` (`luch/engine.ts:598-612`) → цикл на `CHARACTER_FPS = 60` всё время, пока Луч в `approval`, `searching` или `sleeping`. `approval` приходит из агрегата сессий (`src-tauri/src/observe/model.rs:471`) и может ждать часами — примерно втрое дороже обычных 20 fps. Варианты для решения пользователем: дыхание во сне (0,29 Гц) рисовать на частоте огня; подпрыгивание при `approval` оставить на 60, но ограничить по времени. Без решения по виду не трогать.

### (e) Голос: если когда-нибудь в Mayak

- Переносить нечего (Swift, AVAudioEngine, SFSpeechRecognizer, Foundation Models). Ценны принципы: выключен по умолчанию; ворота VAD перед распознавателем; полудуплекс; правила конца реплики; после ответа не слушать без вопроса; самовосстановление с лимитом частоты; **никаких одобрений разрешений голосом**; в логах без слов.
