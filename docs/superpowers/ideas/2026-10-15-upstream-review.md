## Идеи, не начатые

1. **Больше агентов через хуки: Copilot CLI, Muse Code, OpenCode, Amp, Hermes** (upstream `windows/src-tauri/src/agents.rs`, `hook/src/normalize.rs`, `reply.rs`). Самое близкое нашему направлению. Не начато, потому что ни один из этих CLI не установлен на этом ПК, а форматы хуков известны только из upstream (см. `2026-10-07-upstream-review.md`, раздел про форматы агентов). По нашим правилам такое не пишется вслепую. Порядок, если брать: Copilot CLI и Muse (формат как у Claude, есть Windows), затем остальные. Условие: CLI установлен и один раз запущен, чтобы снять реальные события.
2. **Недельный итог по понедельникам** (upstream `recap.rs`, `recap/summary.ts`): время, сессии, файлы и строки, команды, разрешения, топ-агент и проект, картинка для шеринга. Нужен собственный журнал истории (сейчас вкладка Stats считает только токены), поэтому это отдельный проект со спецификацией.
3. **Крестик «свернуть» в шапке острова** (#558). Мелочь, нужна только если Esc и «Скрыть» неудобны.
