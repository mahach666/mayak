# Mayak: персонаж Луч вместо Mochi

Дата: 2026-10-09. Источник: идеи §26 (ребрендинг персонажа), обсуждение с пользователем 2026-10-08/09. Ветка `feature/luch-character`.

Это подпроект А ребрендинга: персонаж, приветствие, иконки, имя. Звуки — подпроект Б, отдельная спецификация.

## 0. Зачем

Mochi, его облик, выражения, анимации, имя, иконка и звуки принадлежат автору Coucou и не входят в MIT (`LICENSE-ASSETS.md` upstream): форк, который распространяется, должен иметь своё имя, иконку, персонажа и звуки. Код движка (состояния, анимации, механика) — под MIT, его оставляем.

Персонаж Mayak — **Луч** (по-английски Luch): живой огонёк-дух.

## 1. Облик

Утверждённый облик — прототип **G4**:
- шейдер: `design/luch/luch-g4.frag.glsl`;
- страница-прототип со всеми состояниями: `design/luch/luch-prototype.html`.

Референс пользователя — картинка огонька, по которой сняты мерки. В репозиторий она не кладётся.

Координаты: `p` от −1 до 1 по коробке персонажа, ось y вверх.

- **Тело.** Широкий круглый комок с покатыми плечами: центр (0.01, −0.11), полуразмеры 0.44 × 0.33.
- **Язык пламени.** Один большой язык из середины тела:
  - высотой примерно 2/3 тела, кончик около (−0.09, 0.66);
  - наклонён влево, кончик загибается влево гребнем;
  - внутри светлый внутренний язычок с оранжевой обводкой.
- **Огонь живой, но стилизованный:**
  - силуэт плавно «дышит», крупная медленная волна бежит вверх по языку;
  - лёгкая эрозия только у верхушки;
  - мелкой рваной бахромы нет.
- **Цвет слоями, как в рисованной анимации:**
  - тонкая красно-оранжевая кайма;
  - ярко-жёлтое тело;
  - светлая сердцевина;
  - лёгкие мазки внутри.
- **Палитра покоя:**

  | Слой | Цвет |
  |---|---|
  | deep | `#E0380A` |
  | mid | `#FF7410` |
  | light | `#FFBC34` |
  | core | `#FFF0C2` |

- **Лицо.** Крупная кремово-жёлтая панель со скруглёнными углами: центр (0.03, −0.1), полуразмеры 0.32 × 0.22, радиус 0.2.
- **Глаза.** Маленькие тёмно-коричневые (`#2A170B`) вертикальные овалы:
  - центр пары (0.09, −0.095), шаг ±0.093;
  - размер 0.022 × 0.04;
  - моргание, взгляд.
- **Всполохи.** Маленькие язычки пламени отщипываются от кончика языка и по бокам, поднимаются, уменьшаются и гаснут. Неподвижных «висящих» кусков нет.
- **Искры.** Редкие точки, поднимаются вокруг.
- **Свечение.** Тёплое, считается от спокойного силуэта, без эрозии, поэтому фон не мерцает.
- **Руки.** Кремовые овалы с оранжевой каймой у нижних углов тела: (−0.4, −0.28) и (0.48, −0.18). Видны только во время жеста (§3.4).

## 2. Устройство (подход 1: движок остаётся, меняется отрисовка)

- **`BotEngine`** (`windows/src/mochi/engine.ts` → `windows/src/luch/engine.ts`) по-прежнему ведёт:
  - состояния, эмоции, твины, частицы;
  - механику рук (`hands`, `greet()`, `waveStart/waveUntil`);
  - активности.

  Меняется только `draw()`: тело, руки-варежки и румянец Mochi заменяются отрисовкой Луча. Публичный API движка не меняется, поэтому `island.ts` и `minibots.ts` меняются только в импортах и мелочах.
- **Новые модули в `windows/src/luch/`:**
  - `fire.ts` — общий WebGL-рендерер огня (шейдер G4):
    - один контекст на всё приложение;
    - большой остров, мини-пилюли и приветствие по очереди рендерятся в его область и копируются `drawImage` на свои холсты;
    - униформы: время, рост, живость, яркость, палитра, высота языка, руки.
  - `face.ts` — 2D-слой поверх огня: глаза и их формы, моргание, взгляд.
  - `fallback.ts` — упрощённое 2D-пламя (силуэт тела и языка градиентами, те же лицо и глаза). Рисуется, когда:
    - WebGL недоступен;
    - контекст потерян (`webglcontextlost`) — до восстановления.
- **Что остаётся из 2D-движка, перерисованное под пропорции Луча:**
  - значки состояний («…», «!», «?», точка);
  - частицы (сердечки, звёзды, искры, «z», нотки, дым вместо капли пота);
  - предметы активностей (ноутбук, кружка, наушники);
  - минуты помодоро.
- **Переименование.** Папка `mochi/` → `luch/`. Упоминания Mochi в коде и комментариях → Луч, кроме ссылок на upstream-исходники в комментариях-«портах».
- **Нагрузка:**
  - огонь рендерится только в кадрах, которые остров уже рисует;
  - спрятанный остров не рисует ничего: правило 0 % CPU сохраняется;
  - шейдер — fbm с 3 октавами.

## 3. Поведение

### 3.1. Состояния агента

Цвет огня берётся из цвета состояния, как сейчас у Mochi: deep — цвет с затемнением 25 %, mid — сам цвет, light — с осветлением 45 %, core — кремовый с оттенком 8 %. В покое — палитра §1.

| Состояние | Облик |
|---|---|
| idle | Спокойное пламя, редкие всполохи, моргает, поглядывает |
| working | Живость ×1,5, значок «…» |
| thinking | Взгляд вверх, медленная пульсация яркости, «…» |
| searching | Глаза бегают влево-вправо, «…» |
| approval | Подпрыгивает, язык вспыхивает выше импульсами, глаза широкие, «!» |
| question | Наклон, «?» |
| error | Пламя ниже и потрескивает, глаза-чёрточки, дымок, точка |
| finished | Радостные глаза, сноп искр, точка |
| ratelimit | Пламя низкое и слабое, уставшие глаза, точка |
| sleeping | Тусклый, живость ×0,35, язык низкий, глаза закрыты, «z» |
| dizzy | Глаза-спирали, пламя шатается |

### 3.2. Эмоции

Взаимодействие как у Mochi: клик — annoyed, три клика подряд — dizzy, курсор 2 с на Луче — love.

| Эмоция | Облик |
|---|---|
| love | Глаза-сердечки, огонь розовеет, сердечки |
| surprised | Глаза-точки, пламя подскакивает |
| proud | Глаза-звёзды, язык вытягивается, искры |
| wink | Один глаз подмигивает |
| yawn | Пламя оседает, рот-овал |
| happy | Радостные глаза, подскок |
| annoyed | Глаза-чёрточки, огонь краснеет, клубы дыма |

### 3.3. Активности (`island/activity.ts`, как сейчас)

- **Работа (помодоро):** ноутбук перед Лучом.
- **Короткий перерыв:** кружка с паром парит рядом. Рук нет.
- **Длинный перерыв:** сон.
- **Музыка:** наушники и нотки.

### 3.4. Руки

Механика Mochi: руки выезжают только для жеста, с прежними таймингами. Сейчас жест один — приветствие. Механика в движке сохраняется для будущих жестов.

### 3.5. Мини-Луч в пилюлях и компактном острове

- Огонь горит цветом пилюли (`task.color` → палитра по §3.1).
- Рисуются только огонь и глаза: без искр, всполохов, рук и мазков.
- Должен читаться в 22 px.

### 3.6. Превращение при перетаскивании файла

`morph` сохраняется в движке. Облик: Луч сворачивается в круглый уголёк. Функция сейчас выключена (`CHAT_ENABLED=false`), отдельной отрисовки коробки нет.

## 4. Приветствие при запуске: «искры, как от зажигалки»

Заменяет `windows/src/mochi/greeting.ts`. Должно быть плавным, а не топорным:
- у каждого движения есть разгон и торможение, перелёт с возвратом, сжатие-растяжение;
- линейных движений нет;
- искры летят по физике (скорость, тяжесть, хвосты);
- огонь всё время живой.

Раскадровка (около 4,4 с; итоговые тайминги — после превью):

| Время | Событие |
|---|---|
| 0,00–0,35 с | Остров раскрывается из полоски: короткий «вдох» вниз, раскрытие с лёгким перелётом |
| 0,45 с | Чирк 1: вспышка внизу по центру, веер 6–8 искр вверх, падают под тяжестью, хвосты, гаснут за 0,4 с |
| 0,85 с | Чирк 2: искр больше, одна падает и тлеет 0,2 с, гаснет |
| 1,25 с | Чирк 3: сноп искр, одна занимается — огонёк с голубоватым основанием, «вдох», подрастает |
| 1,6–2,2 с | Огонёк поднимается к центру и разгорается в Луча, в движении вытягивается, за ним искры |
| 2,2 с | Приземление: сплющивается и отпружинивает; глаза открываются и моргают |
| 2,45–3,55 с | Руки выезжают, правая машет (механика Mochi), глаза радостные, звук приветствия |
| 3,6–3,9 с | Руки прячутся, радостный подскок |
| 3,9–4,4 с | Луч уменьшается и улетает на место в компактном острове, остров сворачивается, появляется текст |

**Сохраняется из нынешнего приветствия:**
- курсор придерживает приветствие, до `greetHoverCollapseDelay` = 10 с;
- уведомление прерывает его вместе с отложенными звуками (`interrupt()`);
- тихий режим — без звука;
- `onComplete` ведёт автомат как сейчас.

**Звуки до подпроекта Б:**
- чирки — короткие из нынешних;
- занявшийся огонёк — `pop`;
- взмах — `greet`.

**Процесс:**
1. Сначала страница-превью `windows/dev/greeting-preview.html` (как `dev/upload-preview.html`): ползунок времени, пауза, покадровый просмотр, повтор.
2. Пользователь одобряет превью.
3. Только после этого приветствие встраивается в остров.

## 5. Иконки

- **Иконка приложения:** Луч на тёмном скруглённом квадрате.
- **Значок трея:** упрощённый силуэт огня с точками-глазами, читается в 16 px.
- **Как рисуются.** `windows/scripts/gen-icons.mjs` считает формулу огня G4 на процессоре, в один фиксированный момент времени, без зависимостей, как сейчас. Иконки остаются «нарисованными кодом».
- **Утверждение.** Перед утверждением — просмотр в 16, 32, 48 и 256 px.

- **Звуки** (подпроект Б). Пока звучат звуки Coucou, раздавать Mayak нельзя.
- Новые жесты рук, гардероб, свой цвет персонажа на пилюлю.

## 8. Проверка

- **Узловые проверки в `windows/scripts/checks/`** (`npm run check`) для чистых функций:
  - палитра по цвету состояния;
  - раскадровка приветствия по времени: фазы, рост, руки, позиция и размер в каждый момент;
  - соответствие состояние/эмоция/активность → облик (форма глаз, высота языка, значок).
- **Вживую в dev-приложении через CDP:**
  - каждое состояние и эмоция;
  - мини в пилюлях;
  - приветствие от запуска до компактного острова;
  - прерывание уведомлением;
  - запасное 2D-пламя при принудительно выключенном WebGL.
- **Нагрузка:**
  - CPU спрятанного острова — 0 %;
  - для открытого острова фиксируются CPU и GPU, бюджет — не тяжелее нынешнего Mochi более чем вдвое по CPU.
- **Сборка:** `npx tsc --noEmit`, `npx vite build`, `cargo test --workspace`.

## 9. Порядок работ

1. Рендерер огня (`fire.ts`) и лицо (`face.ts`), запасной режим (`fallback.ts`).
2. `draw()` движка на Луча; поведение по §3.1–§3.4.
3. Мини-Луч (§3.5).
4. Превью приветствия → одобрение пользователя.
5. Приветствие в острове.
6. Иконки → одобрение пользователя.
7. Имя, строки, README.
