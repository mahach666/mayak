# Mayak: вкладка чата как «запускатель» агента

Дата: 2026-10-07. Статус: на согласовании. Идея №17 (`docs/superpowers/ideas/2026-10-06-mayak-next-ideas.md`), переосмысленная пользователем.

## 1. Цель и решения пользователя

Встроенный чат острова работает только через ключ API. Это отдельный платный продукт, у пользователей подписки его почти никогда нет. Поэтому вкладка чата становится **запускателем**. Пользователь вводит вопрос, при желании перетаскивает файл, выбирает агента и проект и нажимает «Отправить». Открывается этот агент, в нужном проекте, с вопросом в поле ввода. **Сам вопрос не отправляется**: последнее слово за пользователем в окне агента.

1. Выбор агентов ограничен тем, что установлено на компьютере.
2. **Проект по умолчанию** — проект последней активной сессии острова. Рядом с полем есть переключатель проекта.
3. **Ключ API остаётся опцией.** Если ключ Anthropic сохранён, в списке агентов есть ещё «Claude API (answers here)». Это прежний чат с ответом прямо в острове, без изменений.
4. **Codex:** готового адреса «новый тред с вопросом» у Codex нет (§2). Вопрос кладётся в буфер обмена. Если на передний план вышло окно Codex, вопрос вставляется туда автоматически (`Ctrl+V`). **Enter не нажимается никогда.**

**Пересмотр после приёмки (2026-10-07).** Codex убран из списка агентов: у него нет адреса «новый тред с вопросом», в закрытый Codex Desktop вставка не попадала, в открытом открывался текущий тред, а не новый. Код целей Codex оставлен (функция `launcher::offered` фильтрует их), чтобы вернуть, когда у Codex появится такой адрес.

**Вне объёма:** ответы агента в острове (кроме API); очередь задач (идеи §18); Codex в терминале.

**Правила проекта сохраняются:**
- Ничего не отправляется агенту без явного действия пользователя в окне агента.
- Нет опроса в покое.
- Существующие виды, кроме вкладки чата, не меняются.

## 2. Цели запуска (замер 2026-10-07 на машине пользователя)

| Агент | Как найти | Как открыть с вопросом | Проверено |
|---|---|---|---|
| Claude Desktop | протокол `claude` зарегистрирован (`HKCU\Software\Classes\claude\shell\open\command`) | `claude://code/new?q=<вопрос>&folder=<папка>[&file=<путь>]…` — новая сессия Code в папке, вопрос в поле | да: сессия в `mayak`, текст в поле, не отправлен |
| Claude в Cursor | `%USERPROFILE%\.cursor\extensions\anthropic.claude-code-*` | сначала поднять окно Cursor с проектом (механизм «Open», §4 переключения окон и воркспейсы), затем `cursor://anthropic.claude-code/open?prompt=<вопрос>` | да: вкладка Claude, текст в поле, не отправлен |
| Claude в VS Code | `%USERPROFILE%\.vscode\extensions\anthropic.claude-code-*` | то же с `vscode://anthropic.claude-code/open?prompt=` | по коду расширения (тот же обработчик `/open`) |
| Codex Desktop | пакет `OpenAI.Codex` (протокол `codex` в `HKCU\Software\Classes`) | буфер обмена → открыть приложение → если его окно на переднем плане, `Ctrl+V` | адреса с вопросом нет (найдены только `codex://threads/<id>`, `settings`, `review`) |
| Codex в Cursor / VS Code | `…\extensions\openai.chatgpt-*` | буфер обмена → поднять окно проекта → открыть панель Codex (`cursor://openai.chatgpt/`) → **без автовставки** (§4) | маршрута с вопросом в расширении не найдено |

Файлы, перетащенные в остров (копия в «inbox» Mayak):
- для Claude Desktop — параметром `file=`;
- для Claude в редакторе — `@<путь>` в начале вопроса;
- для Codex — путь отдельной строкой в тексте вопроса.

## 3. Выбор агента и проекта

- **Список агентов** строится при открытии вкладки из найденных целей §2. Порядок:
  1. Claude Desktop;
  2. Claude в Cursor;
  3. Claude в VS Code;
  4. Codex Desktop;
  5. Codex в Cursor;
  6. Codex в VS Code;
  7. Claude API, если ключ сохранён.
- Последний выбранный агент **запоминается** в настройках (`launcherAgent`).
- **Проект** — корень проекта последней активной сессии острова (по `since` в снимке). Переключатель показывает проекты из снимка. Если сессий нет — «No project», тогда агент открывается без папки, где это возможно.
- **Claude Desktop без папки:** `claude://code/new?q=…`.
- **Редактор без проекта:** URI уходит в последнее активное окно редактора.

## 4. Запуск (Rust, команда `launcher_open`)

Команда принимает `{ agent, prompt, root?, files[] }`. Её работа идёт в отдельном потоке, как у `session_open`.
- **Claude Desktop:**
  - собрать URI, каждый параметр в `encodeURIComponent`;
  - вопрос ограничить 8000 символами, файлов — не больше 10;
  - открыть его через системный обработчик протокола (`ShellExecuteW` / `open`).
- **Claude в Cursor или VS Code:**
  1. окно проекта ищется тем же выбором, что у «Open» (`focus::pick_window`, с воркспейсами);
  2. если окно найдено, оно поднимается (`raise`);
  3. если не найдено, запускается `cursor <root>` / `code <root>` и до 15 секунд с шагом 250 мс ожидается появление окна с этим проектом. Опрос идёт только в этот момент, после него нет;
  4. затем открывается `cursor://anthropic.claude-code/open?prompt=…`.
- **Codex Desktop:**
  1. вопрос (с путями файлов) кладётся в буфер обмена Windows;
  2. приложение открывается через `explorer shell:AppsFolder\OpenAI.Codex_<publisherId>!App` (имя берётся из установленного пакета);
  3. в течение 5 секунд ожидается, пока на переднем плане окажется окно процесса Codex;
  4. если оказалось — `Ctrl+V` через `SendInput`. Если нет — ничего не вставляется.
- **Codex в редакторе:** буфер обмена, окно проекта (как для Claude), `cursor://openai.chatgpt/`. **Без автовставки**: фокус может оказаться в редакторе кода, а вставка туда изменила бы файл.
- **Результат** возвращается острову как `Opened | OpenedPasteYourself | Failed(reason)`. Остров сворачивается, как после «Open». Для `OpenedPasteYourself` и для Codex без автовставки показывается короткая подсказка «Paste the question with Ctrl+V».
- **Лог:** одна строка без текста вопроса и путей: `launcher: agent=… outcome=…`.

## 5. Остров (вкладка чата)

Вид `prompt` перестраивается:
- **поле ввода**, как сейчас;
- **приложенный файл** (если перетащен) с крестиком «убрать»;
- **строка из двух выпадающих списков:** агент и проект;
- **кнопка «Send»**, она же `Enter`; `Shift+Enter` — новая строка.

При выборе «Claude API» вид работает как прежний чат: ответы в острове, история. Перетаскивание файла по-прежнему ведёт в этот вид. Кнопка «Ask a question» на карточке файла остаётся. Новые элементы — в стиле приложения, существующие виды не меняются.

## 6. Тесты и приёмка

**Тесты (Rust):**
- Сборка URI для каждой цели: кодирование, кириллица, `&`/`#` в вопросе, несколько `file=`, лимиты.
- Поиск установленных целей на временных каталогах: несколько версий расширения — берётся любая; нет расширения — цели нет.
- Текст для буфера с путями файлов.
- Решение «вставлять или нет» по процессу переднего окна: чистая функция над (pid окна, pid приложения).

**TS:** `tsc`, сборка.

**Приёмка вживую:**
1. Claude Desktop: сессия в выбранном проекте с вопросом и файлом.
2. Claude в Cursor:
   - проект, открытый в своём окне;
   - проект внутри воркспейса;
   - проект, который не открыт.
3. Codex Desktop: вопрос вставлен в поле, если окно поднялось; иначе подсказка.
4. Codex в Cursor: панель открыта, вопрос в буфере, подсказка.
5. Claude API с ключом работает как раньше (если ключ есть).
6. Ничего не отправилось само.
