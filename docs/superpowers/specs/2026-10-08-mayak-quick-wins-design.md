# Mayak: понятный предпросмотр в Settings, страница при открытии острова, «Открыть» нужный чат Claude Desktop

Дата: 2026-10-08. Источник: идеи §27, §28, пользователь согласовал объём («бери 1–3»). Ветка `feature/quick-wins`.

## 1. Предпросмотр изменений в Settings (идеи §27.1)

Сейчас после «Включить», «Установить», «Обновить» или «Удалить» показывается сырой унифицированный дифф в текстовом поле. Пользователю непонятно, что это.

- **Блок** с заголовком «Что изменится в `<путь к файлу>`» (путь как есть).
- **Строки диффа** — только для чтения (не `textarea`), моноширинно:
  - добавленные зелёным с «+»;
  - удалённые красным с «−»;
  - контекст серым;
  - заголовки `@@` скрыты или приглушены;
  - длинные строки переносятся.
- **Строка о бэкапе:** «Перед записью Mayak сохранит копию рядом: `<имя бэкапа>`», если план её даёт; иначе общий текст про копию рядом.
- **Кнопки «Применить» и «Отмена»** рядом с блоком:
  - «Отмена» закрывает предпросмотр без записи;
  - «Применить» — существующая запись с отпечатком плана.
- **Если изменений нет**, вместо диффа строка «Изменений нет», «Применить» недоступна.
- **Применяется ко всем предпросмотрам Settings:** интеграция Codex, ответы из острова для Claude и Codex, и прочие места с тем же потоком. Логика записи не меняется.
- **Тексты** на 7 языках.

## 2. Какая страница открывается из свёрнутого острова (идеи §28)

- **Настройка** в Settings → General: «Открывать при нажатии» (`openOnClick`). Значения:
  - `sessions` (по умолчанию — как сейчас);
  - `overview`;
  - `stats`;
  - `focus`;
  - `apps`;
  - `last` — последняя страница, которую пользователь сам открывал вкладкой.
- **Где действует:** открытие пользователем — наведение или клик на свёрнутый либо компактный остров, `Alt+M`, пункт трея «Open Mayak».
- **Где не действует:** тревоги и карточки (ждёт тебя, готово, ошибка, ответы, фаза помодоро) открывают свою карточку, как сейчас.
- **Нет сессий.** Сейчас для этого случая есть своё поведение (`empty` / `overview`). Если выбрано `sessions`, а сессий нет, — как сейчас.
- **Rust-настройка:** `open_on_click: String`, `serde(default = "sessions")`. Неизвестное значение → `sessions`.
- **Тексты** на 7 языках.

## 3. «Открыть» для сессии Claude Desktop (идеи §27.2)

Сначала разведка (только чтение), есть ли у Claude Desktop адрес конкретной сессии Code и как сопоставить её с `~/.claude/sessions`.
- **Если адрес есть** — «Открыть» ведёт прямо в чат. Если сессия не сопоставилась — поднять приложение, как сейчас.
- **Если адреса нет** — поднять приложение, как сейчас, и коротко подсказать в острове: «Claude Desktop открыт — выберите чат “<имя проекта>”».

### 3.1 Итог разведки (`2026-10-08-mayak-desktop-deeplink-research.md`)

- **Маршрут:** `claude://code/continue?session=local_<id>`. Найден в коде Claude Desktop 2.26454.2.0, не документирован.
  - Открывает существующую неархивную сессию. Ничего не отправляет и новую сессию не создаёт.
  - Если сессия не найдена, открывается главная страница Code.
- **Сопоставление:** поле `hostSessionId` в `~/.claude/sessions/<pid>.json` у сессий с `entrypoint == "claude-desktop"`. Оно равно `local_<uuid>`, проверено на трёх живых сессиях.
  - Mayak принимает значение, только если оно проходит шаблон `^local_[A-Za-z0-9-]{1,64}$`; иначе поле игнорируется.
- **Решение для «Открыть» у сессии Claude Desktop:**
  1. Как сейчас, поднять окно Claude.
  2. Если у сессии есть `hostSessionId`, открыть `claude://code/continue?session=<id>` через обработчик протокола. Значение подставляется в адрес только после проверки шаблоном.
  - Если Desktop адрес проигнорирует (старая версия, ссылки отключены), пользователь просто окажется в окне Claude, как сейчас.
- **Не используется:**
  - `claude://resume?…`: импортирует чужие сессии и без диалога помечает папку доверенной;
  - `claude://code/needs-input`: может открыть другую ожидающую сессию.
- `hostSessionId` не логируется и в интерфейсе не показывается.
