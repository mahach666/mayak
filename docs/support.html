Support

Found a bug or want something added? Open an issue and say what you did, what you expected and what happened. The latest log lines help (see “Where is the log?”).

The installer is flagged

The Windows builds are not code-signed. SmartScreen says “unknown publisher”: choose More info → Run anyway. Microsoft Defender has flagged earlier unsigned builds as Trojan:Win32/Wacatac.H!ml, a machine-learning false positive. The SHA-256 of every file is in SHA256SUMS.txt in the release, and you can build Mayak yourself from the source.

The Mac says “Mayak” was not opened

The Mac build is signed ad hoc, not by an Apple developer. Choose Done, then System Settings → Privacy & Security → Open Anyway. It needs macOS 13 or newer, on Apple silicon.

My agent's sessions do not show

Open Settings → Agents and enable the integration for Claude Code, Codex or Antigravity (Enable…). Mayak shows you what it will change in the agent's config, makes a dated backup and writes only after you confirm. Without the hooks the sessions still appear from the agents' own files, but permission requests do not reach the island.

The Claude or Codex limits are empty

Mayak reads the Claude limits from the cache Claude Code keeps in .claude.json, and the Codex limits from Codex itself. Until the agent has run and fetched its limits, there is nothing to show; start a session and check again.

The Agents tab says “not installed” or “not signed in”

The tab runs your own CLI, with its own login. Install the CLI and sign in once in a terminal (claude auth login, codex login…), then send the message again.

Where is the log?

%LOCALAPPDATA%\Mayak\mayak.log on Windows, ~/.local/share/mayak/mayak.log on a Mac. It holds event and tool names, project names and HTTP status codes, no commands, content or keys, and stays on your machine.

Uninstalling

Remove Mayak from Windows' Apps list (or drag it out of Applications), use Disable… in Settings → Agents first if you want your agents' configs back as they were, and delete %APPDATA%\Mayak and %LOCALAPPDATA%\Mayak. Your keys are in the Credential Manager (a Mac: the Keychain) under the name io.github.mahach666.mayak.
